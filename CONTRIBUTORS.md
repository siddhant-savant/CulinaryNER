## How to Contribute

We welcome contributions! Areas for improvement:

- Additional cuisine types (French, Thai, Mexican, etc.)
- New entity categories (DIETARY_RESTRICTION, PRESENTATION)
- Multi-language support
- Error analysis and corrections
- Model improvements (BERT, transformers, etc.)

Please open an issue or pull request to discuss contributions.
